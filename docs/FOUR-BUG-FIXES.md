# ארבעת התיקונים המבוקשים

- זהות: Gather אוסף תשע ספרות. תשובה בתשע ספרות עוברת לאישור לפני בדיקת מקשי ניווט, ולכן גם מספר שמתחיל ב־0, 5, 8 או 9 מתקבל. עזרה וניווט בשדה זה הם מקש יחיד וסולמית. מספר קצר אינו נשמר כתשובה.
- אישור תשובה: כניסה ללא מקש או בחירה לשמוע שוב משמיעה את התשובה בתוך Gather. אין הפניה שקטה בלבד לאותו נתיב. התיקון היה כבר קיים ונשמר.
- אישור שליחה: שתיקה או מקש אחר אינם מאשרים. בטלפון נשמר אישור נפרד למסמך ולנמען, ותחילת שליחה בודקת אותו. התיקון הקודם הורחב כדי לחסום עקיפה דרך נתיב send.
- מייל: נמען מוגדר בתחילת שיחת הניסיון. לפני הצעת שליחה נבדקת תקינותו והוא מוקרא. הקשה על 1 מאשרת את אותה כתובת; כתובת חסרה, לא תקינה או ששונתה מאז ההקראה חוסמת שליחה.

לא נוספו רכיבי דמה או שירותים חדשים. נוספו בדיקות רגרסיה לקובץ tests/e2e-call.test.js; בדיקות HTTP דורשות התקנת ספריות npm שעדיין חסרות בסביבה. 22 בדיקות offline ובדיקות תחביר עברו. לא בוצעה שליחת מייל או שיחה חיה.

בדיקה חוזרת הוסיפה קשירת האישור למסמך ולנמען המדויקים, ביטול אישור אחרי שינוי והתאוששות מכשל הגדרות לפני תחילת שליחה.
