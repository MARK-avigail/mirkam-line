# בדיקת התאמה והפרדת כניסה — ממשק 8

## התנהגות נדרשת וממומשת

- בפתיחת האפליקציה מוצגת כניסת ניהול: שם משתמש וסיסמה בלבד, ללא תפריט פנימי, קודי משתמשים, טופס הקמה או הגדרות שרת. הסתרת אזורים פנימיים קיימת כבר ב־HTML לפני הפעלת JavaScript, וב־CSS היא נאכפת גם מול פריסות flex/grid.
- אימות מוצלח בשרת פותח את אזור הניהול. שגיאת סיסמה או תשובה לא תקינה אינן פותחות אותו.
- מסך הניהול נפרד מכניסת משתמשי השירות. שיחות/מסמכים/הודעות בתפריט המנהלת משתמשים בנקודות API של ניהול ובהרשאת בעלת מערכת, ללא דרישה להזין קוד של משתמש. מדובר בצפייה ניהולית, לא התחזות למשתמש ולא יצירת שיחות בשמו.
- ברשימת משתמשים לא נשלחים ולא מוצגים קודי כניסה, PIN או גיבובי סיסמה. יצירה/איפוס מפורשים ממשיכים למסור סוד חדש לבעלת הרשאה לצורך מסירה פרטית; זו אינה רשימת סיסמאות קיימות.
- יציאה, סיום זמן התחברות או תשובת 401 נועלים את הממשק ומנקים תוכן פרטי. תשובה ישנה לבקשה שנשלחה לפני הנעילה אינה יכולה להחזיר רשימת משתמשים למסך.
- תפקידים מוגבלים אינם מקבלים גישה לשיחות, מסמכים והודעות דרך API של בעלת המערכת. ההגנה אינה מסתמכת על הסתרת כפתורים.
- MFA נשאר מוסר לפי בקשת המשתמשת הקודמת; שם משתמש וסיסמה עדיין נדרשים.

## בדיקות

337 בדיקות מקומיות עברו: 96 ליבה, 34 HTTP, 11 צוות, 16 PWA, 31 חיבור מקומי, 23 עדכונים, 25 ממשק, 101 הרשאות HTTP. מטריצת ההרשאות בודקת פעולות שונות מול אנונימי, אסימון שגוי, משתמש רגיל, תמיכה, כספים והתחברות בעלת מערכת שפגה.

בדיקות הממשק מפעילות את סקריפט האפליקציה עם DOM מדומה. בדיקות HTTP מפעילות את מטפל השרת ומסד בדיקה. אין כאן בדיקת מסך Samsung אמיתי או הוכחה שכל ספק חיצוני פעיל. יש לאמת את מסך הכניסה ואת הכניסה בחשבון הקיים בטלפון לאחר העדכון.

## החלה ומגבלות

השרת צריך למשוך את השינוי ולהתחיל מחדש; האפליקציה צריכה להפעיל עדכון חתום 8. עדכון אחד אינו מחליף את השני. החשבון והסיסמה הקיימים אינם נמחקים.

הגדרת בעלת מערכת ראשונה אינה מוצגת במסך הכניסה הרגיל. היא נשארת תהליך נפרד עם קוד ההקמה הראשוני; המשתמשת הנוכחית כבר יצרה חשבון. כתובת השרת שכבר נשמרה נשארת במכשיר. מכשיר חדש ללא כתובת שרת יצריך הגדרת חיבור לפני שימוש; ההפצה הנוכחית אינה פתרון onboarding ללקוחות חדשים.

טרם הושלמו: אחסון קבוע, ספקים חיצוניים מאומתים, סנכרון חי, שליטה בין מכשירים ואימות פעולות מיקרופון/הורדות בכל מערכת הפעלה. מספר הבדיקות אינו הצהרה שכל הבאגים נפתרו.
