# פתיחה ללא אינטרנט והמיתוג החדש

הגרסה שומרת רק את מעטפת התוכנה הציבורית: HTML, קוד ממשק, עיצוב וסמלים. אין שמירה של תשובות API, שיחות, מסמכים או פרטי כניסה במטמון הזה.

עדכון ב־Codespaces:

```bash
git pull --ff-only origin main && bash scripts/restart-codespaces.sh
```

פתחו את פורט 3000 דרך Ports בחיבור הפרטי ורעננו את התוכנה. המתינו להודעה ״מוכן לפתיחה ללא אינטרנט״ לפני בדיקה במצב טיסה. השרת חייב להיות זמין בהכנה הראשונה. אין צורך להסיר את ההתקנה כדי לעדכן את המסכים; עדכון האייקון המותקן תלוי בדפדפן ועלול להתעכב.

לאחר ההכנה, המעטפת השמורה מוצגת גם בכשל רשת או בתשובות שרת 401/403/500/503. כניסה, AI, מסמכים ושליחה דורשים שרת זמין. אין הבטחת זמינות אם הדפדפן מחק את אחסון האתר. Codespaces הוא סביבת פיתוח שיכולה להיעצר; להשקה דרוש שרת קבוע. התקנה אינה מחליפה שרת.

אימות: 156 בדיקות Node עברו, מתוכן 16 בדיקות התנהגות של Service Worker בסביבה מדומה. נבדקו מטמון ציבורי, כשלי שרת, מצב ללא רשת, מניעת שמירת API ושמירת מטמון קודם כשהתקנה חדשה נכשלת. לא בוצעה בדיקה בדפדפן הטלפון או בדיקת הפעלה חיה בסביבה זו.
