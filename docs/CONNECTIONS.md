# שלושת חיבורי השירות הנדרשים

אלה שלושה חיבורים. רק הראשון הוא מפתח API יחיד; Twilio דורש מזהה וסוד, ומייל דרך Gmail דורש סיסמת אפליקציה.

1. **OpenAI — AI ותמלול**: פתחו חשבון ב־https://platform.openai.com/, בחרו או צרו Project, הגדירו חיוב API, ואז צרו מפתח ב־https://platform.openai.com/api-keys. בשרת הגדירו `OPENAI_API_KEY`. מנוי ChatGPT אינו מחליף חיוב API.
2. **Twilio — טלפון**: פתחו חשבון ב־https://console.twilio.com/. מתוך פרטי החשבון העתיקו `Account SID` אל `TWILIO_ACCOUNT_SID` ו־`Auth Token` אל `TWILIO_AUTH_TOKEN`. צריך גם מספר בעל יכולת Voice וכתובת שרת HTTPS. הגדירו Voice webhook מסוג POST ל־`BASE_URL/ivr/voice`. מפתח API נוסף מסוג SK אינו נדרש בקוד הנוכחי.
3. **Gmail — מייל יוצא**: בחשבון שישלח את המייל הפעילו אימות דו־שלבי דרך https://myaccount.google.com/security, וצרו סיסמת אפליקציה דרך https://myaccount.google.com/apppasswords. הגדירו `SMTP_USER` לכתובת השולח, `SMTP_PASS` לסיסמת האפליקציה, `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`. אם החשבון אינו מאפשר סיסמאות אפליקציה, נדרש SMTP אחר שנתמך בקוד.

את הסודות מכניסים רק ל־`.env` בשרת או למנהל הסודות של האירוח. אין לשלוח אותם בצ׳אט. בנוסף הגדירו `TEST_EMAIL` לכתובת הנמען, `PILOT_PIN` לקוד השיחה ו־`ADMIN_TOKEN` לקוד ניהול. אלה הגדרות מקומיות, לא מפתחות ספק נוספים. כתובת השולח יכולה להיות שונה מכתובת הנמען.

הקו הקיים מוגבל לניסיון עם נמען קבוע. כתובת המייל מוקראת לפני השליחה, והקשה מפורשת על 1 מאשרת את המסמך ואת הכתובת. אין שליחה כשכתובת הנמען חסרה או לא תקינה.
