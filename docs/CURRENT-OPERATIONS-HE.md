## עדכון משולב — הפרעה לתשובות ואבחון מתוך הניהול
המשתמשת אישרה שפקודת ההתקנה האחרונה עדיין לא הורצה. אין להציג תיקוני קוד כאילו כבר נשמעו בקו.

- השמעת תשובה לפני הקלטה עוברת כעת בתוך Gather: אפשר לחזור ב־8 או לצאת ב־7 בזמן ההשמעה, בלי למחוק שיחה שמורה. השינוי חל גם על פתיחת הקלטת הודעת משפחה ופנייה למשרד; אינו מוסיף הסברים טכניים לטקסט המושמע.
- הגשר מכבד את timeout השתיקה של Record (חמש שניות), במקום להסתמך על ברירת מחדל SDK אחרת.
- סיום שיחה מעביר אבחון מצומצם לשרת: משך, שלב, סיבת סיום וקודי ספק מספריים. שמות, טלפונים, קודים אישיים ותמלול אינם כלולים באבחון. אחרי התקנת העדכון, בעלת המערכת יכולה ללחוץ ״בדיקת ניתוקים אחרונים״ במסך חיבורים ומוכנות. הנתונים מוגבלים לעשר שיחות סיום והגישה לבעלת המערכת בלבד. נתוני עבר שלא נרשמו אינם משוחזרים.
- משימה שהסתיימה לאחר ניתוק מסומנת כהושלמה גם בלי להחיות את השיחה.
- מצב הגדרות הקו מכיר כעת גם בטוקן גשר Voice Elements; מצב הפקס קורא את הגדרת המתאם במקום false קבוע. נוכחות הגדרות אינה אימות הרשמה או מסירה.

### חוסן התקנת העדכון המשולב
תוקן deploy/apply-voice-experience.sh: בנייה מתבצעת לפני עצירת שירות; כשל בהחלפת היישום, בהפעלת הגשר או בהרשמה לספק מפעיל ניסיון חזרה לשני הקונטיינרים המקוריים, עם מזהה יישום תואם למרחב הרשת של הגשר. קונטיינרים שנכשלו נשמרים לבדיקה. אין שחזור אוטומטי של נתוני משתמש או של הגדרות פרטיות. הצלחה מוכרזת רק אחרי VOICE_REGISTERED, ולא אחרי המתנה קבועה של שלוש שניות. גם אז נדרשת שיחה אמיתית.

שלוש בדיקות Python (שישה מסלולים, כולל ארבע הזרקות כשל) עברו מול סקריפט ההתקנה האמיתי עם Docker מדומה: כשל בנייה, כשל יישום, כשל הפעלת גשר, כשל הרשמה, היעדר אישור הרשמה והצלחה. לא הופעל Docker אמיתי ולא שונו קונטיינרי השרת. הרצה חוזרת: npm run test:voice-release.
