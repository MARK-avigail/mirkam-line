# שימוש בקו עתירה

פתחו את כתובת האתר שהמפעיל נתן לכם. קובץ HTML שנפתח מתוך הורדות אינו מפעיל את השירות. בניסיון מקומי, השתמשו בכתובת שמופיעה לאחר הפעלת השרת.

לחצו על ״התחלת מסמך חדש״. בחרו עתירה לבית המשפט המחוזי, ואז את בית המשפט הרצוי. המסלול הזה אוסף פרטים לניסוח מסמך; אינו קובע לאיזה בית משפט נכון לפנות ואינו מגיש את המסמך לבית המשפט.

ענו במילים שלכם. אפשר להקליד, או להקליט בדפדפן נתמך עם הרשאת מיקרופון. להקלטה מרחוק נדרשת כתובת HTTPS. לחצו על ״סיום הקלטה״ כשסיימתם לדבר. התמלול דורש שירות מחובר, ולכן אינו זמין כשהחיבור אינו מוגדר.

לפני כל מעבר, בדקו את התשובה שהמערכת הציגה. אפשר לאשר, לתקן, או לבקש עזרה בניסוח. עזרה בכתיבה אינה מקור לעובדות: ודאו שהניסוח מתאר רק מה שהתכוונתם לומר. כשחסר מידע, העוזר שואל שאלה קצרה. אפשר לחזור לשאלה קודמת; תשובות אחרות שאושרו נשמרות. ניתן לדלג רק על שדות רשות.

בסיום, קראו את המסמך או שמעו אותו, אם מותקן בדפדפן קול עברי. אפשר לבחור פרט לתיקון ולהוריד PDF או Word. מסמך עם פרטים חסרים הוא טיוטה.

בדקו את כתובת המייל. בניסיון שהוגדר למייל קבוע, אין לשנות את הנמען. סמנו את אישור התוכן והנמען, ולחצו על שליחה. קבלת ההודעה בשרת המייל אינה הוכחה שהגיעה לתיבה. בדקו גם ספאם. אם מצב השליחה אינו ודאי, בדקו את התיבה לפני ניסיון נוסף.

״חזרה למסמך שנשמר״ משתמשת במזהה ששמור בדפדפן הזה. אינה מבטיחה שחזור לאחר מחיקת נתוני דפדפן או שימוש במכשיר אחר. ״מחיקת המסמך״ מוחקת את הרשומה המקומית לפי מדיניות השרת; מייל שכבר נשלח אינו נמחק.

התקשרות למספר טלפון אפשרית רק לאחר שהמפעיל חיבר מספר אצל ספק טלפוניה לשרת. האתר אינו מייצר מספר בעצמו. המערכת אינה מוקד חירום, ואין להסתמך על יצירת המסמך כדי לקבל מענה מיידי.
