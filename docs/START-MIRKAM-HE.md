# הפעלת מרקם ליין החדש — צעד אחר צעד

זו גרסת פיתוח חדשה ומאוחדת, ולא תיקון לכפתור אחד ב״קו עתירה״.
היא אינה מותקנת אוטומטית ב־Codespaces ואינה מסונכרנת עם GitHub.

## התקנה בלי לדרוס את הגרסה הישנה

קובץ install-mirkam-line.py מצורף בנפרד למסירה. העלי אותו לתיקיית המאגר
ב־Codespaces. מתוך /workspaces/ki-ativa הריצי:

```bash
python3 install-mirkam-line.py /workspaces/ki-ativa
```

המתקין ייצור תיקייה חדשה /workspaces/ki-ativa/mirkam-line. הוא מסרב לדרוס
תיקייה קיימת באותו שם. אין מחיקה של ki-ativa הישנה או הנתונים שלה.
אם קיימת סביבת Python ישנה תקינה, המתקין יגדיר שימוש בה למסמכים.
ה־OPENAI_API_KEY נשאר Secret של Codespaces; לא מדביקים אותו בקוד.

## בדיקות והפעלה

אם השרת הישן פועל, סיימי אותו בטרמינל שלו באמצעות Ctrl+C פעם אחת.
אחר כך בטרמינל פנוי:

```bash
cd /workspaces/ki-ativa/mirkam-line
npm test
npm start
```

אל תפעילי שני שרתים על 3000. השאירי את הפורט פרטי ופתחי דרך Ports.
הדף החדש אמור להציג Mirkam Line וחמש שלוחות, לא מונה 17 שאלות.

## כניסה ראשונה

בהפעלה הראשונה נוצר mirkam-admin-secret.txt בתיקייה החדשה.
פתחי אותו בעצמך בעורך והעתיקי את תוכנו לשדה קוד הניהול באתר.
אל תשלחי אותו בצילום/צ׳אט ואל תעלי אותו למאגר.
הוא אינו PIN המשתמש, ואינו מפתח OpenAI.

רשמי משתמש בדיקה עם פרטים מומצאים. המערכת תציג קוד משתמש ו־PIN פעם אחת.
רק בעלת המערכת רשאית לאשר מינוי חינם; זו ההגדרה שתשמש לחשבון דודך לאחר
רישום ואימות אמיתי. אין לו הרשאת צוות אוטומטית.

בית משפט/יעד צריך התאמה מאומתת לבית הסוהר לפני שמסלול עתירה ימשיך.
לבדיקת מסך השתמשי בשם ״מחוזי לבדיקה״, בית סוהר בדיקה ומייל בדיקה שבשליטתך.
אל תציגי זאת כיעד רשמי. לאחר מכן נכניס נתונים רשמיים שאומתו.

## מה נבדק ומה לא

קראי MIRKAM-VALIDATION.md ואת MIRKAM-REQUIREMENTS-MATRIX.md. יותר מ־70 בדיקות
מקומיות אינן הוכחה לשיחת טלפון חיה, הגשת עתירה, שליחת פקס או חיוב תשלום.
לא משיקים למשתמשים אמיתיים לפני השלמת הבדיקות והחסמים שסומנו.

שירותי המייל יופעלו לאחר חיבור SMTP מאובטח ובדיקת הודעה אחת לחשבון ניסוי,
כולל בדיקת התיבה בפועל. קרדיטים ל־OpenAI אינם קרדיטים למייל.

## מעטפת Mavrika AI וכניסה אישית

תפריט הצד מרכז את מרקם ליין, השיחות, המסמכים, המשפחה והניהול. הכנת עתירה נפתחת בנפרד, לפי בחירה.
בניהול, פתחי ״הגדרה ראשונית באמצעות קוד הניהול״, הזיני את הקוד המקומי ובחרי יצירת המשתמש האישי. בחרי שם משתמש ושם לתצוגה. שמרי את הסיסמה שנוצרה והוסיפי את מפתח האימות לאפליקציית TOTP. לאחר מכן הכניסה היא בשם משתמש, סיסמה וקוד אימות. אין סיסמה קבועה בקוד.

לחשבונות טלפון שלך ושל דודך: רשמי כל חשבון בנפרד לאחר אימות הפרטים האמיתיים. המערכת יוצרת קוד משתמש וקוד אישי; הם אינם נוצרים מראש בחבילה.
לחשבון דודך, בחרי ברשימת המשתמשים ״הענקת פיקוח טלפוני ללא חיוב״ ואשרי את היקף הגישה. הכניסה הטלפונית הרגילה תציג תפריט פיקוח נוסף בהקשה על 6, לצד חמש השלוחות. תפריט זה מאפשר הקראת שיחות ומסמכים לפי קוד משתמש, מצב שירות ושימוש, סיכום תשלומים מאומתים וחסימה/הסרת חסימה באישור מפורש. צפייה ופעולות מתועדות. אין לו גישה לאישור אנשי קשר או להענקת הרשאות. השיחה עם AI פתוחה גם לנושאים שאינם משפטיים.

ניהול תשלומים מלא עדיין מחייב חיבור לספק סליקה: כרגע מוצגים התשלומים המאומתים בלבד. אין אפשרות לחייב כרטיס או לסמן תשלום כאילו שולם דרך תפריט הפיקוח. עלויות OpenAI וספקים אחרות אינן מסונכרנות; המערכת אומרת זאת במפורש.
