# קו עתירה

יישום ניסיון להכנת עתירה לבית המשפט המחוזי, ב־17 שדות קבועים. מאפשר מילוי בדפדפן או שיחת Twilio בעברית, תמלול OpenAI, עזרה בשאלה והצעת ניסוח המאושרת בנפרד, הקראת המסמך, PDF בעברית, Word ושליחה במייל לאחר אישור מפורש. בחירת בית משפט או הכנת מסמך אינן הגשה לבית משפט. מסלולי תביעות קטנות ועליון עדיין אינם נתמכים.

## התקנה

נדרשים Node.js 22 ומעלה, Python 3, גופן עברי ושרת עם אחסון מתמשך. בלינוקס אפשר להשתמש בגופן DejaVu Sans. ב־Windows הגדירו PYTHON_BIN ו־HEBREW_FONT לפי ההתקנה.

```sh
npm install
python3 -m pip install -r requirements-document.txt
cp .env.example .env
npm run verify
npm test
npm start
```

פתחו http://localhost:3000. אפשר להתחיל למלא ולהוריד מסמכים ללא AI או טלפוניה. ללא מפתח AI הקלטות ועזרה אינן פועלות; המערכת אינה מייצרת תמלול בדוי. מפתחות נשמרים ב־.env בשרת בלבד. אין לשלוח סיסמאות בצ׳אט.

## ניסיון טלפוני

הגדירו OPENAI_API_KEY, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, SMTP, TEST_EMAIL וקוד PILOT_PIN בן 4–10 ספרות. TEST_EMAIL הוא נמען הניסיון שאישרתם. חיבור ציבורי דורש BASE_URL ב־HTTPS, HOST=0.0.0.0 ו־ADMIN_TOKEN אקראי ארוך. הגדירו אצל Twilio Voice webhook מסוג POST ל־BASE_URL/ivr/voice. כל קריאה נבדקת בחתימת Twilio ונקשרת למזהה השיחה.

הקו הטלפוני פועל במצב ניסיון בלבד. בעת שאלה: 9 עזרה, 8 חזרה, 0 חזרה על השאלה, 5 דילוג על שדה רשות. ממתינים לצליל ואז מדברים; מסיימים הקלטה בסולמית. בעת הקלטה המקשים אינם פקודות ניווט. תשובות ותאריכים דורשים אישור; תמלול תאריך צריך להניב יום/חודש/שנה במספרים. אם לא התקבל פורמט תקין מבקשים להקליט מחדש. בשדה זהות אפשר להקיש את כל תשע הספרות, כולל אפס בתחילת המספר; מקשי עזרה וניווט בשדה זה מסתיימים בסולמית. אפשר גם להמתין ולהקליט. הצעת AI דורשת אישור ואפשר לשחזר את הנוסח המקורי.

שרת SMTP מאשר קבלה, ואינו מוכיח הגעה לתיבת הדואר. אם השליחה נותקה, אין שליחה חוזרת אוטומטית. בודקים תחילה את התיבה והספק. הקוד אינו מחבר קו בזק או שולח פקס.

## מסמכים ופרטיות

PDF נוצר באמצעות ReportLab ו־python-bidi או libfribidi. DOCX נוצר כקובץ ZIP תקני עם פסקאות מימין לשמאל. מסמכי ניסיון וטיוטות חסרות מסומנים ״לא להגשה״. נתוני שיחה נשמרים כקובצי JSON פרטיים; אין להשתמש באותו DATA_DIR לבדיקות ולשירות פעיל. הרצת השירות נתמכת בתהליך אחד בלבד; אין להפעיל workers מקבילים על אותם קבצים. מוחקים מסמך דרך הממשק; הקלטות אצל Twilio ונתונים אצל ספקים דורשים מדיניות מחיקה נפרדת.

ראו [מדריך משתמש](docs/USER-GUIDE.md), [ניהול](docs/ADMIN-GUIDE.md), [פרטיות](docs/PRIVACY.md) ו־[מצב מסירה](docs/HANDOFF-codex.md). בדיקות מדומות אינן בדיקת שירות חי. יש להשלים שיחת ניסיון ומייל אמיתיים לאחר חיבור החשבונות. מספר פעיל ואירוח אינם נוצרים באמצעות התקנת הקוד.
