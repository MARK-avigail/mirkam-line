# חיפוש ועדכוני תוכנה

נוסף כפתור חיפוש עם סמל, הפעלה ב-Enter, בסיום עריכה ובזמן הקלדה. מעל התוצאות מוצגים מספר ההתאמות והשאילתה, או הודעה מפורשת שאין התאמות. ניקוי החיפוש משחזר את רשימת המשתמשים. סינון בזמן הקלדה כבר היה קיים; התקלה המדווחת בטלפון לא שוחזרה בסביבת הבדיקה.

נוסף לתפריט הצד מסך עדכוני תוכנה. בדפדפן הוא מסביר שאין צורך בהתקנה מחדש ומאפשר רענון אחרי אישור המשתמש. במעטפת native הוא משתמש במנגנון updateCheck הקיים. אין שינוי במנגנון פריסת השרת.

בדיקות: 1080 בדיקות בחבילה המלאה עברו. לאחר הוספת שתי בדיקות רגרסיה וניקוי פרטי כניסה בפתיחת מסך העדכונים, כל 19 בדיקות shell-dossier עברו שוב (17 קיימות ו-2 חדשות). בדיקות UI מבוססות DOM מדומה; לא בוצעה בדיקה חזותית בטלפון או שיחת טלפון חיה.
