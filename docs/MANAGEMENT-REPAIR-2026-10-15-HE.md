- פעולות ניהול מוסתרות חסומות גם בממשק לפי תפקיד; ההרשאות בשרת נשמרו.

## התקנת העדכון
בשרת בלבד, בתיקייה /opt/mirkam-line: git pull --ff-only ואז bash deploy/apply-management-release.sh.
הסקריפט בונה image לפני עצירת האפליקציה, עוצר את הקונטיינר הקיים, שומר גיבוי פרטי של הנתונים וההגדרות, שומר את הקונטיינר הישן ומפעיל את החדש על אותו localhost:3000. אם ההפעלה/בדיקת health נכשלת הוא מנסה להחזיר את הקונטיינר הקודם; יש לוודא את תקינותו בפועל. אין מחיקת גיבויים או איפוס חשבון.
צפויה הפסקת שירות קצרה בעת ההחלפה. אין שינויים בהגדרות Caddy, בכתובת HTTPS או בסודות. לאחר ההתקנה יש לבדוק HTTPS, כניסה, מפת שלוחות, רשימת עתירות ותצוגה בטלפון.

## חסמים שלא הוסתרו
- חסר מפתח API מוגדר בשרת לפי צילום המשתמשת; מנוי צ'אט אינו מוכיח זמינות API לאפליקציה.
- בחירת ספק/שער לקו ובדיקת שיחה נכנסת, DTMF, זיהוי, ניתוק וחזרה לטיוטה.
- מתאם פקס, תשלום וקבלת מייל משפחתי אוטומטית אינם מושלמים.
- תפקיד הדוד, עריכה ניהולית מלאה של עתירות, שיחות AI חיות ובדיקות עומס נותרו לביצוע.
- SMTP קיים בהגדרות אך משלוח מהשרת החדש והגעה לתיבה עדיין אינם מאומתים.
- BASE_URL שבקובץ ההגדרות המועתק צריך להתאים לכתובת החדשה לפני webhook חי; לא לשנות מפתחות בצ'אט.
