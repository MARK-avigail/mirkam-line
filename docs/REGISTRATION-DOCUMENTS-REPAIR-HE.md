# תיקון פתיחת עתירות ורישום משתמשים — 16 באוקטובר 2026

## מקור התקלה ותיקון
תבנית העתירה כבר הייתה קיימת ב-src/mirkam/documents.js ומשמשת את שירות השיחות. מסך הניהול הציג תשובות גולמיות בלבד. הוספו פתיחת מסמך מלא מתוך רשימת העתירות, תבנית עם שדות להשלמה גם כשאין עתירות, והורדת תצוגת PDF/Word לבדיקה. שלושת המסמכים (עתירה, טיוטת תצהיר, טיוטת אגרה) נוצרים מאותו renderer. תצוגה אינה יוצרת רשומה, אינה שולחת ואינה מאשרת הגשה. קובצי ההורדה מסומנים לבדיקה ולא להגשה.

פרטי כניסה חדשים אינם מופיעים עוד בסטטוס הכללי. הם מוצגים רק אחרי לחיצה ייעודית ונמחקים מהתצוגה במעבר מסך, ביציאה, בהסתרת הדף או לאחר דקה. אין שינוי בקודי משתמש קיימים. לפני איפוס PIN מוצגת בקשת אישור.

רשימת משתמשי הקו מוצגת בכרטיסים עם מצב חשבון. הרשאות פיקוח מיוחדות מופרדות באזור סגור לבעלת המערכת בלבד. הטבת מינוי ללא חיוב אינה מוצגת לתפקיד support. רישום דורש אישור מפורש לבדיקת זהות וזכאות גם בשרת; לא מדובר באימות מול מרשם רשמי. פורמט זהות נשאר תשע ספרות; בדיקת ספרת ביקורת לא נוספה ללא הכרעה לגבי סוגי הזיהוי הנתמכים.

## התקנה ובדיקה
בשרת: cd /opt/mirkam-line && git pull --ff-only && bash deploy/apply-management-release.sh
הסקריפט שכבר הותקן מגבה את הנתונים ושומר את הקונטיינר הקודם. לאחר עדכון יש לרענן את הדפדפן (לקוחות עם קוד ישן לא יוכלו לרשום משתמש ללא שדה האישור החדש).
בדקו: עתירות ומסמכים → הצגת תבנית; עתירה קיימת → פתיחת העתירה והמסמכים; משתמש חדש → אישור אימות → הצגת פרטי כניסה; ניווט אחר → פרטי הכניסה אינם נשארים בהודעה.
אין למחוק את משתמש הבדיקה או לאפס PIN קיים כחלק מהעדכון.
