# הפעלה וחיבור שירותים

השתמשו במחשב מודרני עם גרסת Node.js שנתמכת בפרויקט. Windows 7 אינו יעד נתמך להפעלה החדשה. מפתחות וסיסמאות מוגדרים בשרת בלבד; אין להדביק אותם בצ׳אט או בקוד שנשלח למשתמשים.

1. התקינו את תלויות הפרויקט באמצעות `npm install`.
2. העתיקו את `.env.example` אל `.env`, והחליפו ערכי דוגמה בערכים אמיתיים. לעולם אין לפרסם קובץ זה. בדקו גם את האפשרויות שהגרסה הנוכחית מוסיפה לדוגמה.
3. הפעילו `npm run verify` ו־`npm test`. בדיקות עם שירותים מדומים בודקות את התוכנה ואינן מוכיחות חיבור לשירות חיצוני.
4. הפעילו `npm start`, ופתחו את כתובת השרת. שרת מקומי נגיש ממחשב זה; `localhost` בטלפון מתייחס לטלפון עצמו.

## AI וקול

נדרש חשבון API עם חיוב פעיל ומפתח `OPENAI_API_KEY`. מנוי ChatGPT אינו מפעיל API. התמלול וההקראה מחייבים מנגנוני קול אמיתיים לפי הגדרות הפרויקט. הגדרת נתיב Whisper אינה מתקינה את התוכנה או מורידה מודל. בדקו את הוראות הרכיב שבו בחרתם ואת דרישות המכונה לפני ההפעלה.

העוזר מסייע להבין שאלות ולסדר את מה שנאמר. אינו מאמת את העובדות או מבטיח התאמה משפטית. הגדירו בקרות הוצאה אצל הספק ובתוכנה; יש לבדוק אם בקרת תקציב היא חסימה או התראה בלבד.

## מייל

יש להגדיר SMTP מאובטח. ב־Gmail ייתכן שנדרשת סיסמת אפליקציה, בהתאם להגדרות החשבון ולמדיניות Google; סיסמת Gmail רגילה אינה תחליף בטוח. בניסיון, `TEST_EMAIL` קובע את הנמען ו־`PHONE_PILOT` מפעיל את מצב הניסיון אם נתמך בגרסה. ודאו את הנמען בפועל לפני שליחה. אישור SMTP אינו אישור מסירה לתיבה.

## שרת ציבורי וקו טלפון

אירוח פעיל צריך לספק HTTPS, אחסון מתמשך לנתונים, ניהול סודות ומעקב תקלות. הגדירו `BASE_URL` ככתובת הציבורית המדויקת. `ADMIN_TOKEN` מגן על API הניהול ויש להזינו בממשק רק באתר הנכון. קוד הגישה נשמר בזיכרון הדף ולא באחסון הדפדפן. ללא קוד, הגישה המקומית בלבד מותנית במדיניות השרת; אין לפתוח API לא מוגן לאינטרנט.

נדרש ספק טלפוניה עם מספר וחיבור API. הקוד כולל חיבור Twilio: הגדרת Voice webhook ל־`BASE_URL/ivr/voice` והגדרת Account SID ו־Auth Token בשרת. זמינות מספרים והיתרי חיוג מבתי סוהר צריכים להיבדק עם הספק והגורם הרלוונטי. אין להניח שמספר רגיל או מנוי בזק לבדם מספקים חיבור תוכנה.

בדיקת ״חיבורים״ מציגה אם הגדרות קיימות; אינה בדיקת חיבור חיה. השלימו ניסיון מדורג: בקשת AI אמיתית, תמלול הקלטה, PDF בעברית, שליחה לתיבת ניסיון, ולבסוף שיחה מלאה. בדקו גם ניתוק, שתיקה, תיקון שדה, שגיאת ספק ומצב שליחה לא ודאי. אל תפעילו ניסיון מחדש לשליחה כאשר ייתכן שההודעה הראשונה כבר התקבלה.

לפני שימוש מעבר לניסוי יש לבחון אבטחה, הרשאות, גיבוי ושחזור, מדיניות שמירה, ניטור ועלויות, ולקבל בדיקה מקצועית של תבניות ודרישות הגשת המסמכים. שירות יצירת מסמכים אינו מוקד חירום או הגשה אוטומטית לבית משפט.
