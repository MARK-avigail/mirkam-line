# התקנות Android ו־Windows — גרסת בדיקה 0.4.0

הקוד אורז את מסכי מרקם ליין בתוך ההתקנה. Windows משתמש ב־Electron ו־Android ב־Capacitor/WebView מקומי. אין טעינת מסך הבית מאתר מרוחק ואין תלות בפתיחת Chrome. הממשק מבוסס טכנולוגיות ווב, כפי שקורה בתוכנות מותקנות רבות.

## עדכון 19 באוקטובר 2026

המשתמשת הבהירה שמחשב הוא סביבת הניהול הראשית. ב־Windows קיימת תוכנת Electron מותקנת, ולא רק אתר בטלפון. גרסת Windows הנוכחית מיועדת ל־Windows 10/11; תאימות למחשב המשתמשת טרם אושרה.

נמצאה בבניית CI תקלה בבדיקות העדכונים: הן ציפו לגרסה 2 כשהחבילה החתומה הייתה גרסה 8. בדיקת Windows ותרחישי Android תוקנו כדי לבדוק את גרסת החבילה הנבדקת; בדיקת החתימה, הטעינה והחזרה לגרסה קודמת נשמרו. 23 בדיקות עדכון ו־31 בדיקות תקשורת/ממשק מקומי עברו. בנייה ובדיקה במערכת הפעלה אמיתית נרשמות בנפרד בהמשך.

## מצב אימות היסטורי

173 בדיקות Node עברו, כולל 17 בדיקות נתיבי תקשורת, חסימת בקשות לא מורשות, הגדרת שרת, ואריזת מסך בית מקומי. בנייה מלאה לשתי הפלטפורמות הצליחה ב־GitHub Actions בריצה 38448345177. תוכנת Windows הופעלה במכונת הבנייה, ובדיקה אישרה טעינת מסך הבית, הלוגו והגשר המקומי ללא שרת מוגדר. נבדק תוכן APK הסופי: קובצי הבית והלוגו ארוזים ואין server.url מרוחק. התקנה במכשירי המשתמשת ושימוש מקוון עדיין לא נבדקו.

## בנייה

הזרימה `.github/workflows/native-build.yml` בונה מתקין Windows ללא חתימת הפצה ו־APK Android לא חתום לחתימה נפרדת. יש מנגנון עדכון ממשק חתום; אין גרסת חנות. אין להתקין APK לא חתום כתוצאה סופית. אפשר למצוא תוצאות תחת Actions לאחר הצלחת שני התהליכים.

בנייה ידנית:

```bash
cd apps/native
npm install
npm run windows
```

Android (Node 22, Java 21 ו־Android SDK):

```bash
cd apps/native
npm install
npm run android:add
npx esbuild android-bridge.js --bundle --format=iife --outfile=www/native-bridge.js
npx cap sync android
cd ../..
python scripts/native/android-icons.py
cd apps/native/android
./gradlew testDebugUnitTest assembleRelease
```

## חיבור והגבלות

במסך המקומי יש הגדרת כתובת שרת HTTPS. נשמרת רק הכתובת במכשיר; אסימוני הכניסה ממשיכים להישמר בזיכרון ולא ב־localStorage. קוד Electron אינו נותן לממשק גישה ל־Node או לקבצי המחשב. תקשורת מוגבלת לנתיבי API ו־health. שגיאות חיבור מוצגות בתוך הממשק ולא מנווטות אותו לאתר.

שרת Codespaces פרטי דורש הרשאת GitHub שאינה קיימת בהתקנה המקומית. לבדיקת פעולות מקוונות נדרש endpoint מתאים; אין להניח שהכתובת הפרטית הישנה תעבוד ביישום המקומי. אין צורך בשרת לפתיחת המסכים המקומיים.

אותו חשבון מול אותו שרת רואה את הרשומות הקיימות. סנכרון חי בין מכשירים, פתרון התנגשויות, שימוש אישי במסמכים במצב לא מקוון, שליטה בין מכשירים, הורדת PDF ושיתוף ב־Android, והקלטה במכשירים דורשים עדיין בדיקות/פיתוח. הם אינם מוכרזים כגמורים.

שמות השלוחות הוחלפו במקור המשותף לממשק ולקול, בלי לשנות ספרות וניתוב. שם העוזר ״ליין״ הוא האחרון שנידון וניתן לשינוי לפני הפצה.
